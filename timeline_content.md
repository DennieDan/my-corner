### March 2026

- Tags: 😘, RAG, love it
- Heading: Build a RAG agent
- Content: The agent classifies an input item to corresponding Harmonized System Codes (HS-Code), based on the _Singapore Trade Classification, Customs, and Excise Duties 2022_

- Project: Autonomous Regulatory Auditor Agent (ARAAg)
  - Thumbnail: araag_thumbnail.png
  - Objectives: Products importing to and exporting from Singapore under Singapore Customs are required to be classified into Harmonized System Code (HS-Code), following the [Singapore Trade Classification, Customs, and Excise Duties 2022](https://file.go.gov.sg/stcced2022.pdf) document. Manually searching and scanning a 700-page document is a tedious work for business with mutliple categories of products. This agent uses RAG to classify products into HS-Code.
  - User Guide: Pick the corresponding LLM provider and model that you want, please follow the instructions. Input the description of the product that you want to search for HS-Code, be as detailed as possible.
    Suggested Questions

    What is the HS-Code of Coconut Candy with rice paper wrapper?
    What is the HS-Code of gold necklace with a silver pendant?

  - Tech Stacks: Python, LangGraph, LangChain, ChromaDB
  - Buttons: View app (https://classifier-agent.dandinh.net/ui/), GitHub Repo (https://github.com/DennieDan/classifier-agent)
