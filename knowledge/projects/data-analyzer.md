## Purpose and audience

Dan built Data Analyzer, also described on her website as the Data Analytics Chatbot, to make exploratory data analysis more accessible to people who are not comfortable writing Python or R code.

Users can upload CSV or XLSX datasets and ask questions in natural language. The application can return data insights and generate plots from the uploaded data.

## Technology and delivery

The public website identifies PandasAI, Python, and Streamlit as the core technology stack. The reviewed résumé also describes a GPT-4o and PandasAI backend that translates natural-language requests into Pandas operations.

Dan deployed the project through Render with a CI/CD workflow and wrote technical documentation and user guidance. The source code and sample Titanic dataset are available at https://github.com/DennieDan/data-app.

The authoritative live application URL is https://data-analyzer-ybzy.onrender.com.
