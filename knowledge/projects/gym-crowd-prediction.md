## Cloud project summary

The NUS Gym Crowd Prediction project is Dan's cloud-based machine-learning project. It uses AWS Lambda and Amazon EventBridge to collect data for predicting future gym crowd levels.

## Problem addressed

The NUS Gym Crowd Prediction project aims to predict future gym crowd levels so people can plan gym visits. Existing occupancy information shows current conditions, while this project asks whether a gym is likely to be crowded at a future time, such as 3 p.m. the next day.

The project was marked ongoing on Dan's public timeline in June 2026.

## Technology

The project uses AWS Lambda and Amazon EventBridge for gym crowd-data collection. Its public stack also lists scikit-learn and Seaborn for machine-learning work and Open-Meteo for weather data.

The approved project source does not list Amazon EC2 or Kubernetes. Those technologies should not be attributed to this project.

The project's public organization is https://github.com/gym-crowd-org.
