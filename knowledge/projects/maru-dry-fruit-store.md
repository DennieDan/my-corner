## Project overview

In August 2022, Dan built the Maru Dry Fruit Store as her first frontend project while studying at APTECH. It is an end-of-course e-commerce website with product listings, product details, a shopping cart, and checkout behavior.

## Technology

The project used AngularJS and jQuery. The approved project source does not list React, so React must not be attributed to this project.

The source code is available at https://github.com/DennieDan/Group2_T1.2208.M0_Eproject1.
